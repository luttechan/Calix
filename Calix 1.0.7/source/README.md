# Calix 1.0.7

버전 폴더의 run_windows.bat 실행.

종료는 왼쪽 아래 종료 버튼을 사용합니다.

로고 시작 화면은 메인 화면이 실제로 표시될 때까지 맨 위에 유지됩니다. 시작 중에는 클릭해도 사라지지 않습니다.

달력은 전체 폭으로 표시합니다. 날짜 안의 유형 배지를 누르면 커서 근처에서 상세 정보를 엽니다.
상세 창에서 강의 / Type / 할 일 이름을 골라 편집합니다. 여러 일정은 필터와 이름 검색으로 찾습니다.
닫기는 오른쪽 위 닫기 또는 Esc입니다. 유형을 고르는 동안 창을 유지합니다.
유형은 작은 한 줄 칩으로 표시하며 테마에서 글래스 효과를 끌 수 있습니다.
완료한 과제는 달력에서 옅게 구분합니다.
공휴일 버튼에서 임시공휴일을 추가하거나 기본 공휴일 표시를 바꿀 수 있습니다.
설정 > 기타 > 특수 일정 등록에서 가톨릭 일정을 켤 수 있습니다. 기본값은 꺼짐이며 2020–2027년 전례력을 포함합니다.
같은 창의 ???를 켜면 매년 6월 27일에 클로네 생일을 표시합니다.
기본 공휴일 자료는 2020–2050년이며 향후 지정 변경은 수동 설정 또는 버전 업데이트로 반영합니다.
1일이 일요일인 달에서 달력 표시가 한 주 어긋나던 오류를 수정했습니다.
과제 / 영상은 각각 독립된 검색과 필터를 사용합니다. 목록이 비면 초기화를 눌러 전체를 확인할 수 있습니다.

- 홈: 오늘 할 일과 남은 일정
- 달력: 날짜 두 번 클릭으로 일정 추가, 사용자 유형과 색상 저장
- 반복 일정: 매일 / 매주 / 매월, 최대 52회
- 완료 체크, 검색, 과목과 유형 필터, 변경 되돌리기
- 학교 일정: 이름 / 사용자 유형 / 메모 편집, 동기화 후에도 유지
- 시간표: 교수와 강의실 표시, 남은 과제와 영상, 분 단위 이동과 색상 선택
- 일기장: 일반 일기 / 비밀 일기, 자동 저장, 제목과 날짜 검색
- 일기 서식: 굵게 / 기울임 / 밑줄 / 취소선 / 글자색
- 메뉴 > 파일: ICS 내보내기, 개인 자료 백업과 복원
- 테마: 핑크 / 스카이블루 / 민트 / 퍼플 / 다크
- 테마 설정에서 앱 실행 중 마감 15분 전 알림을 켤 수 있습니다.

비밀 일기는 12자 이상의 암호로 보호합니다. 잊으면 복구할 수 없습니다.
창을 벗어나거나 5분간 입력이 없으면 잠깁니다. 암호는 저장하지 않습니다.
제목, 날짜, 본문, 서식을 AES-256-GCM으로 함께 암호화합니다.
암호 키는 Argon2id로 계산합니다. 절대적인 해킹 불가능을 보장하지는 않습니다.
컴퓨터 자체가 감염되거나 일기가 열린 상태의 메모리까지 보호하는 기능은 아닙니다.

개인 백업에는 수동 일정, 학교 일정의 개인 편집값, 유형, 시간표, 과목 이름, 일반 일기와 암호화된 비밀 일기가 들어갑니다.
일반 일기는 평문입니다. 로그인 암호와 쿠키는 백업에 포함하지 않습니다.
복원 전 자료는 사용자 자료 폴더의 backups에 자동 보관합니다.
암호 변경 전의 백업은 이전 암호가 필요합니다.
