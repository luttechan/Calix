# 1.0.1 UI 재구성

공식 제품 자료를 검색해 일정 중심 구조와 재질 표현을 참고했습니다.

| 자료 | 적용 |
|---|---|
| [Notion Calendar](https://www.notion.com/product/calendar) | 일정에 집중하는 화면, 간결한 탐색과 명령 메뉴 |
| [Amie Tasks](https://amie.so/documentation/features/tasks) | 수동 할 일과 학교 일정을 같은 달력에서 확인 |
| [Morgen](https://www.morgen.so/) | 일정과 할 일을 함께 계획하는 구조, 기한을 달력에 표시 |
| [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials) | 반투명 탐색과 컨트롤, 읽기 선명한 본문 표면, 투명도 끄기 |

이를 Calix에 맞게 해석해 다음과 같이 변경했습니다.

- 달력은 기본 전체 폭으로 표시. 상시 오른쪽 패널 대신 필요할 때 상세 패널 열기
- 요약 카드는 홈에 집중. 달력에서 큰 요약 카드를 제거해 셀 높이 확보
- 요일 행은 34px로 줄이고, 셀 안 날짜는 왼쪽 위에 네이티브 QLabel로 표시
- 운동, 할 일, 영상 등은 18px 한 줄 칩. 넘치는 유형은 +N으로 정리하고 전체 개수는 접근성 설명과 도움말로 제공
- 홈의 큰 여백과 요약 카드 높이 축소. 목록 행도 압축해 정보 밀도 개선
- 작은 명령 메뉴, 좁은 탐색 레일, 일관된 모서리와 여백
- 글래스 배경은 640×420 이미지 한 장만 재사용. 화면 크기나 DPI마다 큰 이미지를 새로 보관하지 않음
- 날짜, 본문과 폰트는 선명도 우선. 배경 효과에 글자를 합성하거나 흐리게 처리하지 않음
- 테마에서 글래스 효과를 끌 수 있음
- 제공된 Pretendard Variable 사용. 400 / 500 / 600 / 700 굵기와 한글/숫자 실제 글리프 검사

기존 29일 영상 오버레이 오류는 별도로 수정했으며, 새 구조에서도 날짜와 목록 일치를 검사합니다.
