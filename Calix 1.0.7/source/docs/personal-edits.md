# 개인 편집값

학교가 제공하는 일정 키 assignment:과목ID:과제ID 또는 movie:과목ID:영상ID에 개인 편집값을 연결합니다. 제목이나 마감 날짜가 바뀌어도 같은 키의 편집값을 유지합니다. 학교가 새 ID로 일정을 다시 만들면 새 일정으로 취급합니다.

원본 제목, 마감, 완료 상태는 학교 동기화 자료에 보관하고 이름 / 사용자 유형 / 메모만 event_customizations에 따로 저장합니다. 기본 유형을 선택하면 학교의 과제 또는 영상 표시로 돌아갑니다. 학교 일정의 완료 여부와 마감은 여기서 바꾸지 않습니다.

새 백업 형식 2에는 개인 편집값과 현재 숨겨진 일정의 편집값도 들어갑니다. 형식 1 백업을 복원하면 현재 편집값과 그 유형은 유지합니다. 같은 학교 계정에서 사용합니다. 비밀 일기는 복호화하지 않습니다.

배경은 불투명 루트에 고정 크기 색상 이미지를 Source 합성으로 다시 그립니다. 이동이 끝나면 한 번 더 그리며 배경 캐시는 이동이나 크기 변경으로 늘어나지 않습니다.
