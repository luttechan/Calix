# 공휴일과 메모리

공식 실시간 제공처: 한국천문연구원 특일 정보
https://www.data.go.kr/data/15012690/openapi.do
공휴일 조회: getRestDeInfo. API 사용에는 공공데이터포털 활용 신청과 서비스 키가 필요합니다.

현재 앱은 API 키 없이 동작하는 2020–2050년 기본 표를 제공합니다. python-holidays 0.107의 한국 공휴일 자료를 빌드 시 생성했으며, 앱 실행 시 이 라이브러리를 가져오거나 서버에 접속하지 않습니다. 기본 표는 현재 알려진 규칙에 따른 자료이며 미래의 임시공휴일이나 규정 변경을 자동으로 보장하지 않습니다.

2026년 노동절과 제헌절의 공휴일 지정은 인사혁신처 자료로 확인했습니다.
https://www.mpm.go.kr/mpm/comm/newsPress/newsPressRelease/?mode=list&searchCondition=title&searchKeyword=%EA%B3%B5%ED%9C%B4%EC%9D%BC
기본 자료의 출처와 생성 버전은 asset/calendar/kr_public_holidays.json에 기록합니다. 생성 도구는 tools/build_holidays.py, 생성 도구의 라이선스는 asset/calendar/HOLIDAYS-MIT.txt입니다.

공휴일 버튼에서 날짜와 이름을 저장합니다. 공휴일 표시를 끄면 기본 공휴일도 숨길 수 있습니다. 기본으로를 누르면 그 날짜의 개인 설정을 지웁니다. 직접 추가한 휴일은 삭제되고 기본 휴일은 원래 이름과 표시로 돌아갑니다.

개인 설정: %APPDATA%\LutteLaurent\Calix\holidays.db. 학교 계정을 바꾸거나 동기화해도 유지합니다. 앱의 개인 백업 형식 3에 포함하며 형식 1/2 복원 시 기존 공휴일 설정을 보존합니다. 공휴일은 학습 과제와 별도로 표시하므로 오늘 할 일과 남은 일정 수에 더하지 않습니다.

완료 과제는 38% 불투명도로 합성한 색을 사용합니다. Qt 텍스트에 투명 효과를 걸지 않고 불투명한 색으로 미리 합성해 Windows GDI의 글자 깨짐을 피합니다. 완료와 미완료가 섞인 날은 배지를 분리합니다.

전환 이미지는 직접 작은 이미지에 렌더링하여 전체 해상도 이미지를 먼저 할당하지 않습니다. 2장 합계 최대 7MiB이며 전환 완료 또는 중단 시 해제합니다. 배지 스타일이 같으면 다시 설정하지 않습니다.

메모리 검사는 임시 자료의 일정 500개, 시간표, 일반 일기와 가톨릭 축일 표시를 이용하며 1600×1000에서 홈 / 달력 / 상세 창 / 공휴일 / 영상 / 과제 / 시간표 / 일기장을 80회 반복합니다. Windows 작업 메모리와 운영체제 최대 작업 메모리, 위젯과 닫힌 창의 참조 수를 기록하며 운영체제 메모리 비우기 기능은 사용하지 않습니다. 이미지 캐시는 4MiB로 제한합니다. 이 목표는 메인 창의 일반 사용 기준입니다. 로그인 브라우저 프로세스와 비밀 일기의 암호 계산은 별도 작업입니다.


가톨릭 축일과 기념일 표시는 기본으로 꺼져 있습니다. 설정 > 기타 > 특수 일정 등록의 가톨릭 일정에서 켭니다. 주교회의 공개 전례력의 2020–2027년 자료 중 축일, 성인 기념일과 선택 기념일의 날짜와 이름을 추려 asset/calendar/catholic_feasts.json에 보관합니다. 기도문, 독서 본문, 미사 해설은 포함하지 않습니다.

주일과 전례 시기에 따라 생략되거나 옮겨진 기념일은 해당 연도 공식 표를 따릅니다. 모든 성인의 고정 축일 사전을 매일 덧붙이는 방식은 아닙니다. 내장 자료가 없는 연도는 종교 날짜를 추정해서 표시하지 않습니다. 자료 추가는 앱 업데이트 때 반영합니다.

축일은 보라색 안내로 공휴일과 분리하며 학습 일정 수와 휴일 수에 더하지 않습니다. 이름이 길면 말줄임하고 커서나 날짜 상세 패널에서 전체 이름을 볼 수 있습니다. 옵션을 끄면 원본 데이터 캐시를 비우며 표시 레이블은 42개 이내에서 재사용합니다. 개인 백업에 표시 옵션도 포함됩니다.

메모리 반복 검사에서는 가톨릭 표시 옵션도 켜서 검사합니다.

표시 중인 월 주변의 날짜만 Qt 날짜 서식에 넣고, 지나간 월의 서식은 비웁니다. 연간 성인 축일 전체를 매번 위젯 서식에 넣지 않도록 제한했습니다.

메모리 측정용 Windows 자료형은 한 번만 생성합니다. 호출마다 새 ctypes 구조체를 만들면 포인터 형식 캐시에 남아 검사 자체가 메모리를 늘리는 문제가 있어 이를 수정했습니다.

설정 > 기타 > 특수 일정 등록의 ???를 켜면 매년 6월 27일에 클로네 생일을 표시합니다. 가톨릭 일정과 독립적으로 선택하며 공휴일과 과제 수에 더하지 않습니다. 옵션은 holidays.db에 저장하고 개인 백업에 포함합니다. 이전 백업에 이 옵션이 없으면 현재 값을 유지합니다.
