# 보안 검토

2026-10-28 기준 소스와 공개 취약점 기록을 검토했습니다.

- 학교 API 연결은 HTTPS, 지정 호스트, 기본 포트로 제한합니다.
- 자동 계정 입력 시 실행 중인 페이지와 제출 대상 주소를 다시 확인합니다.
- 로그인 쿠키는 메모리에 유지하고 보관본은 Windows DPAPI로 암호화합니다.
- 계정은 Windows 자격 증명 관리자에 저장합니다. 삭제 시 이전 저장 형식도 정리합니다.
- 비밀 일기는 Argon2id와 AES-256-GCM을 사용합니다.
- 저장 실패 중 잠그는 경우 임시 내용은 메모리에서 암호화합니다. 프로세스가 종료되면 미저장 임시 내용은 사라집니다.
- 백업에는 비밀번호와 로그인 쿠키를 넣지 않습니다. 비밀 일기는 암호화 상태를 유지합니다.
- 외부 일정의 툴팁은 HTML로 해석하지 않습니다.
- 로그에서는 인증 헤더, 쿠키, 비밀번호와 토큰을 가립니다.
- 배포본은 Python 3.14.10으로 빌드하고 OpenSSL 보안 패치 수준을 검사합니다. 오래된 빌드 환경은 배포를 중단합니다.

실제 학교 계정에 대한 침투 시험은 수행하지 않았습니다. 같은 Windows 계정을 장악한 악성 프로그램이나 메모리 분석까지 방어한다는 보장은 하지 않습니다.
