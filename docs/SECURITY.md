# 보안

- 계정: Windows 자격 증명 관리자에 저장.
- 쿠키: Windows DPAPI로 암호화.
- 비밀 일기: Argon2id와 AES-256-GCM 적용. 암호 분실 시 복구 불가.
- 백업: 비밀번호와 쿠키 제외. 일반 일기는 평문, 비밀 일기는 암호화 상태로 포함.
- 통신: 학교 API는 HTTPS와 지정 호스트만 허용.
- 업데이트: 공식 GitHub 릴리즈의 SHA-256 확인 후 설치.
- 로그: 인증 정보 가림.

미저장 비밀 일기는 프로그램 종료 후 복구할 수 없습니다.
기기 감염과 메모리 접근은 보호 범위 밖입니다.
