# Calix 1.0.8

## 패치

- 저장소를 최신 소스와 공용 원본 자산으로 통합.
- 배포 ZIP에서 중복 소스, 개발 파일, 미사용 Qt 리소스 제외.
- 앱 코드를 실행 파일에 내장하고 버전 폴더의 Calix.exe로 직접 실행.
- 배포 환경을 Python 3.14.10으로 교체하고 오래된 OpenSSL 배포 차단.
- 주요 화면과 보조 메뉴의 첫 표시 개선.
- 내장 기울임 글꼴로 일기 메뉴 지연 제거.
- 로그인 정보의 저장, 전송 대상, 로그 가림 보강.
- 저장 계정 삭제 추가.
- 비밀 일기 저장 실패 시 잠금 상태에서 임시 내용 보호.
- 종료 처리 중 추가 입력 차단.

- 과제와 영상의 유형별 탐색 및 중복 계산 개선.
- 목록 글꼴 측정 재사용으로 화면 표시 지연 감소.
- 일기 저장 실패 시 화면 이동 방지.
- CPU 고급 가속 비활성 환경의 회귀 검사 추가.

# Calix 1.0.7

- 좌측 하단 종료 버튼과 종료 확인 추가. 창의 X로는 종료하지 않음.
- 미저장 변경 사항이 있으면 저장하고 종료 / 바로 종료 / 취소 제공.
- 로그인 브라우저와 동기화 취소를 함께 요청하고 종료 완료까지 상태 표시.

- 메뉴 전환 시 화면 전체를 다시 그리던 처리 제거.
- 과제 화면 진입 시 숨겨진 홈과 일정 전체를 중복 계산하지 않도록 개선.
- 빠른 연속 메뉴 전환과 창 크기 변경 시 전환 상태 정리.

- 제공된 Pretendard에서 고정 굵기 파일을 생성해 첫 굵기 처리의 지연을 줄임.
- 홈의 남은 일정을 고정된 네이티브 행으로 표시하고 전체 보기로 연결.
- 달력은 처음 열 때 한 번 준비하도록 초기화 분리.
- 긴 일정명은 말줄임하고 전체 이름은 커서로 확인.
- 공개 배포본에는 제공된 Pretendard와 공개 라이선스만 포함.

# Calix 1.0.5

- 완료한 과제를 옅은 배지로 분리. 미완료 과제는 기존 색 유지.
- 달력 우측 상단 버튼을 상세 일정으로 고정.
- 한국 기본 공휴일과 대체공휴일을 오프라인 표시. 2020–2050 기본 자료 포함.
- 공휴일 버튼에서 임시공휴일 추가, 이름 변경, 표시 끄기, 기본으로 복원.
- 직접 설정한 공휴일은 학교 계정과 독립적으로 저장하고 동기화 후 유지.
- 공휴일 명칭을 설날 연휴 / 추석 연휴 / 크리스마스로 정리.
- 가톨릭 축일과 성인 기념일 표시 옵션 추가. 2020–2027년 주교회의 전례력 내장, 기본 꺼짐.
- 개인 백업 형식 3에 공휴일 설정과 가톨릭 표시 옵션 포함. 이전 백업 복원 시 현재 공휴일 설정 유지.
- 큰 창과 높은 DPI에서 전환 이미지 2장을 합계 8MiB 이내로 직접 렌더링.
- 동일한 달력 배지 스타일을 반복 적용하지 않고 화면 밖 날짜 서식의 할당을 제한.
- 이미지 캐시 4MiB 제한. 닫힌 상세 창의 참조를 정리하고 80회 반복 사용 진단 추가.

# Calix 1.0.4

- 로고가 포함된 시작 이미지와 움직이는 대기 표시 추가.
- Qt와 글꼴, 메인 화면을 준비하는 동안 독립된 Windows 창으로 맨 위에 유지.
- 메인 화면 첫 그리기 완료 뒤 시작 화면을 닫아 빈 구간 방지.
- 시작 실패 시 안내와 닫기 버튼을 유지. 로그인 전용 프로세스에는 중복 표시하지 않음.
- 영상과 과제 검색란 위 요약 버튼이 내부 글자와 숫자 폭을 반영하도록 수정.

# Calix 1.0.3

- 홈과 달력 전환 시 배경까지 포함한 불투명 화면을 같은 위치에서 교차 전환.
- 목록 배경과 행을 불투명하게 그려 카테고리 변경 시 검은 배경과 누적 합성 방지.
- 상세 창을 유지되는 보조 창으로 변경. 유형 선택과 다른 일정 선택 중 자동으로 닫히지 않음.
- 여러 일정은 강의 / Type / 할 일 이름 표로 선택. 강의와 유형 필터, 이름 검색 지원.
- 일정 편집 저장 시 선택 표를 초기화하지 않고 해당 행만 갱신.
- 달력에서 누른 유형으로 상세 창을 열고 같은 날의 다른 유형도 선택 가능.

- 기존 일기의 색상과 서식은 보존하며 이전 기본 글꼴만 화면에서 전환
- 공식 캘린더 제품과 Apple 재질 가이드를 참고해 홈, 탐색, 달력 구조 재구성

- 홈 요약 카드와 목록을 압축하고 글래스 테마 및 효과 끄기 추가

- 1일이 일요일인 달에서 달력 오버레이가 실제 날짜보다 한 주 앞 칸에 붙던 오류 수정

- 과제/영상 화면의 검색과 상태를 각각 독립적으로 유지
- 과제/영상 기본 목록은 완료와 기한 경과를 포함한 불러온 전체 일정 표시

- 빈 목록에서 불러온 일정 없음과 필터 결과 없음 구분
- 동기화 직후 목록과 화면 이동 시 검색 결과 즉시 갱신
- 홈의 오늘/남은 일정과 달력 요약에서 지난 일정 제외 규칙 유지
