# Calix iOS 0.1

부산외대 Canvas 일정 관리 앱. iOS 17 이상을 지원합니다.

## 학교 동기화

홈에서 동기화 버튼을 누르고 학교 페이지에 로그인합니다. 로그인 후 Canvas 페이지가 열리면 첫 동기화를 시도합니다. 이후 `동기화` 버튼으로 새로고침할 수 있습니다. 과제와 제출 상태, 응답에 포함된 피드백, LearningX 영상 및 출결을 읽습니다. 읽지 못한 과목과 데이터 유형은 기존 기록을 유지합니다. 메모, 별표, 사용자가 지정한 완료 상태는 다음 동기화에도 유지됩니다.

## iPhone에서 사용할 수 있는 기능

- 홈, 마감 보드, 달력, 과목별 현황과 일정 검색·필터
- 개인·반복 일정 편집, 완료 표시, 별표, 메모, 휴일과 휴강일 지정
- 체크리스트 상태·메모·일정 가져오기, 학기별 시간표, 공강 찾기, 비대면 수업
- 학점 계산기, 출결, 뽀모도로와 자유 집중, 주간 기록
- 일기와 기기 인증이 필요한 비밀 일기
- 프로필 사진, 닉네임, 홈 문구, 테마, 마감과 집중 알림, 기기 인증 잠금
- iOS 개인 데이터 JSON 백업과 병합 복원. 내보내기에는 학교 데이터, 학점, 비밀 일기가 포함되지 않습니다.
- 암호화되지 않은 Windows `.calix` 백업 가져오기. 개인 일정, 체크리스트, 학점, 시간표, 일반 일기, 집중 기록, 휴일을 병합합니다.

## 실행과 검증

`Calix.xcodeproj`를 열어 `Calix` 스킴과 iPhone 시뮬레이터를 선택합니다. 실기기에는 Xcode 서명이 필요합니다. GitHub Actions는 동기화 응답 테스트를 실행하고, Xcode로 빌드한 뒤 시뮬레이터에서 앱을 열어 스크린샷을 저장합니다.

```sh
node --test tests/CanvasSync.test.cjs
```

학교 계정으로 로그인하는 종단 간 검증은 별도로 필요합니다. 암호화된 데스크톱 백업과 비밀 일기 가져오기, 일기 문서 서식, 체크리스트 상태 편집·자동 연결, 동기화 차분 캐시, 데스크톱 개발자 도구와 Windows 업데이트 기능은 현재 이식 범위에 포함되지 않습니다.
