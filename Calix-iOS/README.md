# Calix iOS 테스트 앱

Calix 1.6.30의 홈, 마감 보드, 과목별 현황, 시간표를 iPhone용 SwiftUI 화면으로 옮긴 테스트 프로젝트입니다. 학교 계정 없이 샘플 과제와 영상을 확인할 수 있습니다. 일정 완료 상태는 기기에 저장됩니다.

## 실행

1. Mac에서 `Calix.xcodeproj`를 엽니다.
2. `Calix` 스킴과 iOS 17 이상이 설치된 iPhone 시뮬레이터를 선택하고 `⌘R`을 누릅니다.
3. 실기기에서는 `Signing & Capabilities`의 `Team`을 지정하고 연결한 iPhone을 실행 대상으로 선택합니다. 번들 ID가 이미 사용 중이면 고유한 값으로 변경합니다. [Apple의 기기 실행 안내](https://developer.apple.com/documentation/xcode/building-and-running-an-app)

## 확인할 동작

- 홈에서 오늘 마감 건수를 확인하고 마감 보드를 엽니다.
- 마감 보드에서 과제와 영상을 필터링하고 제목이나 과목으로 검색합니다.
- 일정 상세에서 완료로 표시하면 마감 보드에서 사라지고 과목별 완료율이 갱신됩니다. 앱을 다시 열어도 완료 상태가 유지됩니다. 과목별 현황에서 해당 일정을 열면 완료를 취소할 수 있습니다.
- 시간표에서 요일을 바꿔 수업 시간과 강의실을 확인합니다.

테스트 범위는 샘플 일정과 기기 내 완료 처리입니다. Canvas 로그인·동기화, 알림, 기존 PC 데이터 가져오기는 이후 이식 범위입니다.
